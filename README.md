# Underwater Adventure

A simple 2D endless diving game where you explore the abyss and discover various sea creatures.

## Installation

1.  **Clone the repository (if you haven't already):**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```
2.  **Ensure you have Python installed.** (Version 3.6+ recommended)
3.  **Install Pygame:**
    Open your terminal or command prompt and run:
    ```bash
    pip install pygame
    ```

## How to Play

1.  Navigate to the game's root directory in your terminal.
2.  Run the game using Python:
    ```bash
    python main.py
    ```

## Controls

*   **Down Arrow Key:** Press and hold to dive deeper.

## Gameplay

*   Dive as deep as you can.
*   Encounter different sea animals to add them to your "Discovered" log at the top of the screen.
*   The game is endless!
